# Raw / Evidence policy

本目录保存**经审查的证据快照**或原始日志的引用说明。

## 禁止直接入库

- API key、token、密码；
- 可识别个人的信息；
- 未经确认的内网 IP、主机名和拓扑；
- 无必要的完整模型路径和业务请求正文；
- 大体积日志副本。

## 推荐格式

每个证据文件记录：

- 原始文件位置（可使用 `local-log:`，不保证团队机器可访问）；
- SHA256（若需要保证完整性）；
- 与结论相关的脱敏行号和摘录；
- ServerArgs 的必要子集；
- 哪些信息被省略。

若团队确认远端仓库的敏感级别允许，再把完整日志作为 Git LFS 或外部对象存储链接接入。
